## Recorder

Thank you for contributing.

1. Fork the repo and create a feature branch from `main`.
2. Keep the app a static PWA (no build step required for the site itself).
3. Test locally with `python3 -m http.server` (mic + SW need a real origin).
4. Open a pull request against `main`.

CI deploys from `main` via GitHub Actions to https://recording.silocitylabs.com.
